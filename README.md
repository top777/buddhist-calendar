# 佛历万年历

完全本地离线运行的佛历万年历工具，支持公历、农历、佛历对照，包含十斋日提醒和佛菩萨圣诞标记。

## 版本说明

本项目提供两个版本：

| 版本 | 平台 | 特点 |
|------|------|------|
| **HTML 版** | 网页浏览器 | 可打包为 PWA，支持手机安装 |
| **Python 版** | Windows/Mac/Linux | 桌面应用，界面更大更清晰 |

---

## HTML 版本

### 文件清单

```
离线佛历万年历工具.html    # 主程序（单文件应用）
lunar.js                   # 农历计算库
manifest.json              # PWA 配置文件
service-worker.js          # 离线缓存服务
icon-192.png              # 应用图标（需自行生成）
icon-512.png              # 应用图标（需自行生成）
图标生成器.html            # 图标生成工具
```

### 快速使用

1. **直接打开使用**
   - 双击 `离线佛历万年历工具.html` 即可在浏览器中使用

2. **打包为 PWA（推荐）**
   - 详见 [PWA快速部署指南.md](PWA快速部署指南.md)
   - 支持安卓和 iOS 手机安装

3. **打包为 APK**
   - 详见 [打包指南.md](打包指南.md)

### 功能特性

- 公历、农历、佛历对照
- 十斋日标记（农历初一、初八、十四、十五、十八、廿三、廿四、廿八、廿九、三十）
- 明日斋日提前提醒
- 佛菩萨圣诞标记
- 响应式设计，支持手机、平板、电脑
- 完全离线运行

## Python 版本

### 文件清单

```
佛历万年历.py              # 主程序
requirements.txt           # 依赖包列表
启动佛历万年历.bat         # Windows 快捷启动
打包EXE.bat                # 打包为 EXE 工具
```

### 安装步骤

1. **检查 Python 版本**
   ```bash
   python --version
   ```
   需要 Python 3.6 或更高版本

2. **安装依赖包**
   ```bash
   pip install -r requirements.txt
   ```
   或直接安装：
   ```bash
   pip install zhdate
   ```

3. **运行程序**
   - 双击 `启动佛历万年历.bat`（Windows）
   - 或命令行运行：`python 佛历万年历.py`

### 功能特性

- 完全本地离线运行
- 公历、农历、佛历对照
- 十斋日标记和弹窗提醒
- 佛菩萨圣诞标记
- 生肖、干支信息
- 点击日期查看详情
- 鼠标悬停高亮显示
- 只显示当月日期，界面清晰

## 十斋日说明

十斋日是佛教中每月持戒修行的吉日：

| 类型 | 日期 | 说明 |
|------|------|------|
| 十斋日 | 初一、初八、十四、十五、十八、廿三、廿四、廿八、廿九、三十 | 每月10天 |
| 六斋日 | 初八、十四、十五、廿三、廿九、三十 | 每月6天 |
| 朔望斋 | 初一（朔日）、十五（望日） | 每月2天 |

## 常见问题

### HTML 版本

**Q: 如何在手机上安装？**
A: 使用 PWA 方式：
1. 将文件部署到支持 HTTPS 的服务器（如 GitHub Pages）
2. 手机浏览器打开网址
3. 选择"添加到主屏幕"

**Q: 可以离线使用吗？**
A: 可以！Service Worker 会缓存所有文件，完全离线可用。

**Q: 图标不显示？**
A: 需要使用 `图标生成器.html` 生成 icon-192.png 和 icon-512.png

### Python 版本

**Q: 提示找不到模块？**
A: 执行 `pip install zhdate` 安装依赖

**Q: 如何打包成 EXE？**
A: 双击运行 `打包EXE.bat`，生成的 EXE 文件在 `dist` 目录

**Q: 程序可以移植吗？**
A: 可以！整个文件夹可以复制到任何有 Python 的电脑上运行
