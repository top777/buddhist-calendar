# 佛历万年历 Python 版本 - 使用说明

## 系统要求

- Windows / macOS / Linux
- Python 3.6 或更高版本

## 安装步骤

### 1. 检查 Python 是否已安装

打开命令行（CMD）或终端，输入：
```bash
python --version
```

如果显示 Python 版本号，说明已安装。
如果没有，请从 https://www.python.org/ 下载安装。

### 2. 安装依赖包

**方式A：使用 requirements.txt（推荐）**
```bash
pip install -r requirements.txt
```

**方式B：直接安装**
```bash
pip install zhdate
```

### 3. 运行程序

**方式A：命令行运行**
```bash
python 佛历万年历.py
```

**方式B：双击运行（Windows）**
- 直接双击 `佛历万年历.py` 文件
- 或创建快捷方式

### 4. 创建桌面快捷方式（Windows）

1. 右键桌面 → 新建 → 快捷方式
2. 位置输入：`pythonw "D:\devcode\01_devcode\佛历工具\佛历万年历.py"`
3. 命名为"佛历万年历"
4. 完成

## 功能特性

✅ 完全本地离线运行
✅ 公历、农历、佛历对照
✅ 斋日标记（十斋日）
✅ 明日斋日提前提醒
✅ 佛菩萨圣诞标记
✅ 生肖、干支信息
✅ 点击日期查看详情
✅ 支持跨年月浏览

## 界面说明

### 左侧日历区域
- 顶部导航：上一年、上一月、今天、下一月、下一年
- 日历格子：显示公历日期和农历日期
- 颜色标记：
  - 黄色边框 = 今天
  - 绿色 = 斋日
  - 橙色 = 佛菩萨圣诞
  - 橙色粗体 = 明日斋日提醒

### 右侧信息区域
- 日期详情：公历、农历、佛历、生肖、干支等
- 斋日类型：十斋日、六斋日、朔望斋说明
- 使用说明

## 使用方法

1. **浏览日历**
   - 点击"上一月"/"下一月"切换月份
   - 点击"上一年"/"下一年"切换年份
   - 点击"今天"返回当前日期

2. **查看详情**
   - 点击日历中的任意日期
   - 右侧显示该日期的详细信息

3. **斋日提醒**
   - 启动程序时自动检查
   - 如果今天或明天是十斋日，弹出提醒框

## 常见问题

**Q: 运行时提示找不到模块？**
A: 确保已安装依赖：`pip install zhdate`

**Q: 界面显示不正常？**
A: 确保系统已安装Microsoft YaHei字体，或修改代码中的字体设置

**Q: 如何打包成exe？**
A: 使用PyInstaller：
```bash
pip install pyinstaller
pyinstaller --onefile --windowed 佛历万年历.py
```
生成的exe文件在 `dist` 目录

**Q: 程序可以移植吗？**
A: 可以！整个文件夹可以复制到任何电脑上运行
