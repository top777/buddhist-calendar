# 离线佛历万年历 - 移动应用打包指南

## 方案一：PWA（推荐，最简单）

### 优点
- ✅ 无需打包，直接在浏览器安装
- ✅ 支持安卓和iOS
- ✅ 可离线使用
- ✅ 可添加到桌面

### 步骤

#### 1. 准备图标文件
需要创建两个PNG图标文件：
- `icon-192.png` (192x192像素)
- `icon-512.png` (512x512像素)

可以使用在线工具生成图标：https://realfavicongenerator.net/

#### 2. 部署到服务器
将以下文件上传到支持HTTPS的服务器：
- 离线佛历万年历工具.html
- lunar.js
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

可以使用免费静态托管服务：
- GitHub Pages
- Netlify
- Vercel

#### 3. 安装到手机

**安卓手机：**
1. 用Chrome浏览器打开网页
2. 点击浏览器菜单 → "添加到主屏幕"或"安装应用"
3. 确认安装

**iPhone：**
1. 用Safari浏览器打开网页
2. 点击分享按钮 → "添加到主屏幕"
3. 确认添加

## 方案二：Capacitor（生成真正的APK/IPA）

### 优点
- ✅ 生成真正的原生应用
- ✅ 可发布到应用商店
- ✅ 支持安卓和iOS

### 环境要求
- Node.js (https://nodejs.org/)
- 安卓开发：需要 Android Studio
- iOS开发：需要 macOS + Xcode

### 打包步骤

#### 1. 安装 Capacitor
```bash
npm install -g @capacitor/cli
npm install -g @capacitor/core
npm install -g @capacitor/cli
npm install -g @capacitor/android
npm install -g @capacitor/ios
```

#### 2. 初始化项目
在佛历工具目录下执行：
```bash
# 创建package.json
npm init -y

# 安装Capacitor
npm install @capacitor/core @capacitor/cli

# 初始化Capacitor
npx cap init "佛历万年历" "com.buddhist.calendar"
```

#### 3. 创建配置文件
创建 `capacitor.config.json`：
```json
{
  "appId": "com.buddhist.calendar",
  "appName": "佛历万年历",
  "webDir": "./",
  "bundledWebRuntime": false,
  "server": {
    "androidScheme": "https"
  }
}
```

#### 4. 添加平台
```bash
# 安装安卓平台
npx cap add android

# 安装iOS平台（需要Mac）
npx cap add ios
```

#### 5. 同步代码
```bash
npx cap sync
```

#### 6. 打包安卓APK
```bash
# 打开安卓项目（需要Android Studio）
npx cap open android
```

在Android Studio中：
1. 等待Gradle同步完成
2. 点击 Build → Build Bundle(s) / APK(s) → Build APK(s)
3. APK文件在 `android/app/build/outputs/apk/debug/` 目录

#### 7. 打包iOS（需要Mac）
```bash
# 打开iOS项目（需要Xcode）
npx cap open ios
```

在Xcode中：
1. 选择目标设备
2. 点击 Product → Archive
3. 按提示发布到App Store

## 方案三：Website 2 APK Builder（仅安卓，最简单）

### 工具下载
- 官网：https://www.website2apk.com/
- 或者使用在线工具：https://web2apk.com/

### 步骤
1. 下载并安装 Website 2 APK Builder
2. 打开工具，选择"Website"
3. 输入本地HTML文件路径或网址
4. 配置应用信息（名称、图标等）
5. 点击"Generate APK"
6. 等待生成完成

## 方案四：Cordova（传统方案）

### 安装
```bash
npm install -g cordova
```

### 创建项目
```bash
cordova create buddhist-calendar com.buddhist.calendar "佛历万年历"
cd buddhist-calendar

# 将HTML文件复制到 www 目录
# 复制 离线佛历万年历工具.html 为 www/index.html
# 复制 lunar.js 到 www/

# 添加平台
cordova platform add android
cordova platform add ios

# 构建应用
cordova build android
cordova build ios
```

## 常见问题

**Q: PWA可以离线使用吗？**
A: 可以！Service Worker会缓存所有文件，完全离线可用。

**Q: 如何创建应用图标？**
A: 使用工具生成：https://realfavicongenerator.net/ 或 Photoshop/在线工具

**Q: APK安装后显示不全？**
A: 检查 `capacitor.config.json` 中的 `webDir` 路径是否正确

**Q: iOS打包必须要有Mac吗？**
A: 是的，iOS应用打包需要Mac电脑和Xcode

**Q: 可以发布到应用商店吗？**
A: 可以，但需要：
  - 安卓：开发者账号 $25（一次性）
  - iOS：开发者账号 $99/年
